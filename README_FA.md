# ابزار تبدیل مارک‌داون فارسی به پی‌دی‌اف (Persian-md2pdf)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey.svg)](#)

> **یک ابزار و کتابخانه حرفه‌ای و متن‌باز پایتون برای تبدیل اسناد مارک‌داون (Markdown) به فایل‌های پی‌دی‌اف (PDF) شکیل، کاملاً راست‌چین و با استانداردهای نشر بین‌المللی.**
> دارای پشتیبانی کامل از فرمول‌های ریاضی لاتک (KaTeX)، بلوک‌های کد برنامه‌نویسی، جدول‌ها، کادرهای هشدار و یادداشت گیت‌هاب (Admonitions) و صفحه‌بندی هوشمند.

---

## 🌟 ویژگی‌های برجسته

۱. **چیدمان کاملاً راست‌چین و استاندارد (RTL)**:
   - استفاده پیش‌فرض از فونت زیبا و استاندارد **وزیرمتن (Vazirmatn)** از گوگل فونت به همراه فونت‌های پشتیبان نظیر شبنم، ساحل، بی‌نازنین و تاهما.
   - تراز متنی تمیز و توزیع مناسب فواصل پاراگراف‌ها (`text-align: justify`).

۲. **تفکیک هوشمند جهت متن‌های ترکیبی (Bidi Isolation)**:
   - واژگان انگلیسی، عبارات تخصصی و پرانتزها در میان جملات فارسی دچار به‌هم‌ریختگی یا جابه‌جایی نمی‌شوند.

۳. **رندر فرمول‌های ریاضی و نمادهای لاتک (KaTeX)**:
   - پشتیبانی از فرمول‌های درون‌خطی (`$E = mc^2$`) و فرمول‌های بلوکی چندخطی (`$$ ... $$`).
   - فرمول‌ها به طور خودکار در جهت چپ‌به‌راست (LTR) ایزوله می‌شوند تا جهت کسرها، ماتریس‌ها و نمادهای ریاضی به هم نخورد.

۴. **کادرهای اعلان و هشدار گیت‌هاب (Callouts)**:
   - پشتیبانی از `> [!NOTE]`، `> [!TIP]`، `> [!IMPORTANT]`، `> [!WARNING]` و `> [!CAUTION]`.
   - امکان استفاده از نام‌های فارسی نظیر `> [!نکته]`، `> [!هشدار]`، `> [!مهم]`، `> [!احتیاط]`.

۵. **قالب‌های ظاهری متنوع (Themes)**:
   - `modern`: قالب مدرن با تم رنگی آبی نیلی، مناسب گزارش‌ها و مستندات شرکتی.
   - `academic`: قالب رسمی دانشگاهی با چیدمان استاندارد کتاب و پایان‌نامه.
   - `minimal`: قالب مینیمال سیاه‌وسفید و خلوت با حداکثر کنتراست.
   - `github`: سبک ظاهری مستندات رسمی گیت‌هاب منطبق بر زبان فارسی.

۶. **تبدیل ارقام به فارسی (`--persian-numbers`)**:
   - قابلیت تبدیل خودکار اعداد انگلیسی (0-9) به فارسی (۰-۹) در متن گزارش، در حالی که کدها، فرمول‌های ریاضی و برچسب‌های HTML بدون تغییر و صحیح باقی می‌مانند.

۷. **حالت نظارت زنده (`--watch`)**:
   - نظارت خودکار بر فایل در حین نگارش؛ به محض فشردن کلید Ctrl+S در ویرایشگر شما (VSCode و ...)، فایل PDF بلافاصله کامپایل مجدد می‌شود.

۸. **عدم نیاز به نصب ابزارهای پیچیده یا باینری‌های سنگین**:
   - استفاده مستقیم از موتور هدلس مرورگرهای خانواده کرومیوم (Chrome، Edge، Brave) که از پیش روی سیستم شما نصب هستند.

## 🖥️ راهنمای دستور خط فرمان (CLI)

پس از نصب، دستور `persian-md2pdf` در هر کجای ترمینال یا خط فرمان در دسترس خواهد بود:

```bash
# تبدیل ساده فایل به PDF (فایل با همان نام و پسوند pdf ذخیره می‌شود)
persian-md2pdf document.md

# مشخص کردن مسیر فایل خروجی
persian-md2pdf document.md -o output.pdf

# انتخاب قالب دانشگاهی برای پایان‌نامه و مقالات
persian-md2pdf thesis.md -o thesis.pdf --theme academic

# تبدیل اعداد لاتین متن به ارقام فارسی
persian-md2pdf report.md --persian-numbers

# فعال‌سازی حالت ویرایش و نظارت زنده (کامپایل خودکار با هر ذخیره)
persian-md2pdf report.md --watch

# تبدیل دسته‌جمعی تمامی فایل‌های مارک‌داون یک پوشه
persian-md2pdf ./docs/ -o ./output/

# استخراج نسخه وب HTML به تنهایی
persian-md2pdf document.md --html-only
```

### جدول سوییچ‌ها و تنظیمات خط فرمان

| سوییچ | مخفف | شرح کارکرد | مقدار پیش‌فرض |
| :--- | :---: | :--- | :--- |
| `input` | | مسیر فایل یا پوشه مارک‌داون ورودی | اجباری |
| `--output` | `-o` | مسیر فایل پی‌دی‌اف یا پوشه خروجی | نام فایل با پسوند `.pdf` |
| `--theme` | `-t` | قالب ظاهری (`modern`, `academic`, `minimal`, `github`) | `modern` |
| `--font` | `-f` | نام فونت اصلی فارسی | `Vazirmatn` |
| `--page-size` | | ابعاد کاغذ (`A4`, `Letter` و ...) | `A4` |
| `--margins` | | فواصل حاشیه صفحه (بالا راست پایین چپ) | `20mm 15mm 20mm 15mm` |
| `--persian-numbers` | | تبدیل اعداد 0 تا 9 متن به ارقام فارسی ۰ تا ۹ | `غیرفعال` |
| `--no-katex` | | غیرفعال‌سازی پردازش فرمول‌های ریاضی | `غیرفعال` |
| `--html-only` | | تولید خروجی HTML بدون ساخت PDF | `غیرفعال` |
| `--keep-html` | | حفظ فایل موقت HTML در کنار PDF خروجی | `غیرفعال` |
| `--css` | | مسیر فایل CSS اختصاصی کاربر | `ندارد` |
| `--browser` | | مسیر دستی فایل اجرایی مرورگر | تشخیص خودکار |
| `--watch` | `-w` | نظارت بر تغییرات فایل و کامپایل لحظه‌ای | `غیرفعال` |
| `--version` | `-v` | نمایش نسخه نصب‌شده | |

## 🐍 استفاده در کدهای پایتون (Python API)

می‌توانید این ابزار را در وب‌سرویس‌ها، اسکریپت‌ها یا پایپ‌لاین‌های داده به کار ببرید:

```python
from persian_md2pdf import md2pdf, md2html

# تبدیل ساده
md2pdf("report.md", "report.pdf")

# تبدیل پیشرفته با اعمال تنظیمات
md2pdf(
    input_file="thesis.md",
    output_pdf="thesis.pdf",
    theme="academic",
    font="Vazirmatn",
    page_size="A4",
    persian_numbers=True,
    katex=True,
)

# تبدیل رشته متن مارک‌داون به سند HTML آماده چاپ
html_output = md2html(
    input_source="# عنوان سند\nمتن نمونه با $E=mc^2$",
    theme="modern",
)
```

### تبدیل پوشه‌ای فایل‌ها

```python
from persian_md2pdf import compile_directory

# تبدیل همه فایل‌های .md در پوشه docs به فایل‌های PDF در dist
files = compile_directory(
    input_dir="./docs",
    output_dir="./dist",
    theme="modern",
    recursive=True
)
print(f"تعداد {len(files)} فایل PDF ساخته شد.")
```

## 🔬 نمونه نگارش مارک‌داون

یک نمونه کامل از فایل ورودی مارک‌داون در مسیر `examples/sample_report_fa.md` قرار دارد.

```markdown
---
title: گزارش جامع مدل‌سازی
author: تیم فنی
date: ۱۴۰۵/۰۱/۱۵
---

# گزارش جامع مدل‌سازی

متن پاراگراف با رابطه جرم و انرژی اینشتین $E = mc^2$.

فرمول ریاضی بلوکی:
$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$

> [!NOTE]
> این یک یادداشت مهم در قالب کادر اعلان است.

> [!WARNING]
> این یک کادر هشدار است.
```
